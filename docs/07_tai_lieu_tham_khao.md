# 📚 Tài Liệu Tham Khảo AuraLMS

1. **Tư liệu thiết kế UI/UX**:
   - Phong cách thiết kế: Glassmorphism (Kính mờ) ứng dụng `backdrop-filter: blur()`.
   - Typography: Google Fonts font chữ **Inter** tối giản cho khả năng đọc code.

2. **Thư viện Tài liệu Tham khảo Lập trình**:
   - Vẽ biểu đồ động: [Tài liệu chính thức của Chart.js](https://www.chartjs.org/docs/latest/).
   - Pháo hoa ăn mừng: [canvas-confetti trên npmjs](https://www.npmjs.com/package/canvas-confetti).
   - Thiết kế SPA và ESM: [MDN Web Docs - Javascript Modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules).

3. **Giải thuật Thích ứng (Adaptive Learning Theory)**:
   - Lý thuyết vùng phát triển gần nhất (Zone of Proximal Development - ZPD) của Lev Vygotsky làm nền tảng cho việc chia nhỏ bài giảng cho Vy và nâng cao bài tập cho Nam/Anh.
   - Thang đo nhận thức Bloom (Bloom's Taxonomy) làm cơ sở thiết kế ma trận Rubrics chấm bài luận từ tái hiện kiến thức đến phân tích logic và sáng tạo.
